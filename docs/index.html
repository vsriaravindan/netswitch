01The Permission Block

On Realme GT Neo 3 (ColorOS 13), every standard Android permission grant route is closed. Manifest declared permissions: zero.

pm grant
DENIED
appops set
DENIED
settings put
DENIED
WRITE_SECURE_SETTINGS
DENIED

02The Workaround

PROBLEM

Can’t toggle network mode from your own app.

ColorOS blocks every standard route to grant WRITE_SECURE_SETTINGS. No pm grant, no appops set, no settings put. Your app has no way to flip the SIM network mode programmatically.

SOLUTION

Deep-link, don’t ask.

A CLEAR_TASK deep-link to{' '} Settings$MobileNetworkActivity. The user adds the QS tile (or home-screen widget) and taps it — the Settings app opens directly on the SIM network mode toggle. Two taps, zero permissions.

03How to use it

01

Install Shizuku

NetSwitch uses Shizuku to elevate the deep-link into an actual toggle. Install from Play Store, activate via ADB or root.

02

Install NetSwitch

Download the APK from GitHub Releases. Sideload — no Play Store listing. Verify SHA-256 against the release page.

03

Add the QS tile

Pull down Quick Settings, edit, drag the NetSwitch tile to your active tiles. Or place the home-screen widget.

04

Tap to toggle

Tap once — Settings opens directly on the SIM network mode toggle. Two taps to switch. No permissions required by the app.
